# Unification test cases

Generated by `python main.py demo --markdown` from `fol/catalog.py`;
every row is also checked automatically by `tests/test_unify.py`.

Notation: `{X/t}` means *X is replaced by t*. Variables start with an uppercase letter.

## Basic

| # | Left | Right | Result (Robinson) | Explanation |
|---|---|---|---|---|
| 1 | `a` | `a` | `{}` | Two identical constants unify with the empty substitution. |
| 2 | `a` | `b` | **fail** (symbol clash) | Distinct constants never unify: constants are rigid symbols. |
| 3 | `X` | `a` | `{X/a}` | A variable unifies with any term not containing it. |
| 4 | `a` | `X` | `{X/a}` | Unification is symmetric: the variable may appear on either side. |
| 5 | `X` | `Y` | `{X/Y}` | Two variables: bind one to the other ({Y/X} would be an equally general MGU). |
| 6 | `X` | `X` | `{}` | A variable unifies with itself; no binding is needed. |
| 7 | `X` | `f(Y)` | `{X/f(Y)}` | A variable can be bound to a compound term containing other variables. |

## Compound

| # | Left | Right | Result (Robinson) | Explanation |
|---|---|---|---|---|
| 8 | `f(X)` | `f(a)` | `{X/a}` | Same function symbol and arity: unify the arguments pairwise. |
| 9 | `f(X, b)` | `f(a, Y)` | `{X/a, Y/b}` | Variables can be on both sides; each argument pair contributes one binding. |
| 10 | `f(X)` | `g(X)` | **fail** (symbol clash) | Different function symbols (f vs g) clash. |
| 11 | `f(X)` | `f(X, Y)` | **fail** (arity mismatch) | Same name but different arity: f/1 and f/2 are different symbols. |
| 12 | `f(a, X)` | `f(b, X)` | **fail** (symbol clash) | The first argument pair a = b already fails, whatever X is. |

| 35 | `raining` | `raining` | `{}` | Propositional atoms (arity 0) unify only with themselves. |

## Example trace

```text
$ python main.py unify "f(g(X), X)" "f(Y, a)" --trace
   1. f(g(X), X)  vs  f(Y, a)   same symbol 'f', unify the 2 argument pair(s)
   2. g(X)  vs  Y   bind Y/g(X)   ->   sigma = {Y/g(X)}
   3. X  vs  a   bind X/a   ->   sigma = {Y/g(a), X/a}
   4. SUCCESS: MGU = {Y/g(a), X/a}
```
